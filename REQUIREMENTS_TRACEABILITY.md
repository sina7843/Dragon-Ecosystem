A security review of the DRAGON-03 identity and authentication scope was performed on 2026-07-22. It found one High (per-IP OTP rate limit collapsed to a shared bucket because the API did not trust the reverse proxy and also published port 3000 to the host). The remediation scoped Fastify `trustProxy` to nginx's fixed address and removed the API host port; re-check verdict PASS.
